# Vanshiv — Portfolio

A React + Tailwind portfolio, dark-theme, sidebar nav.

## Edit your content
Everything you'd want to change day-to-day lives in one file:
`src/data/content.js` — name, bio, projects, skills, links, CP profiles.

## Run locally
```
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. Go to vercel.com → New Project → import that repo.
3. Vercel auto-detects Vite. Build command: `npm run build`, output dir: `dist`.
4. Deploy. Add your custom domain under Project Settings → Domains.

## Add your CV
Drop your resume PDF at `public/cv.pdf` — the CV page download button links there directly.
